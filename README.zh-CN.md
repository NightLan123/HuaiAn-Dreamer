# 槐安梦客 · HuaiAn Dreamer

**一个探索 AI 持续人格、情绪、记忆与动机的计算框架。**

> 如果一次对话结束之后，AI
> 仍然能够保留经历、形成稳定倾向，并让内部状态影响未来的理解与行为，我们需要怎样的计算系统？

槐安梦客是一个本地运行的软件与研究项目，尝试回答这个问题。它将通用语言模型与独立的计算心理／认知子系统连接起来。它不是一个新的基础语言模型，不是单纯的人设提示词库，也不宣称已经创造了人工意识。

## 名字的来处

“槐安梦客”这个名字，来自为项目写下的四句诗：

> 槐安旧国曾留姓，  
> 尘世青编未载名。  
> 梦里不知身是客，  
> 醒来偏作世间人。

“槐安”借用了梦中之国的意象，“梦客”则指向一个身处梦境、又以某种方式行走于人间的来客。它既是项目名称的由来，也寄托了我们对记忆、身份与持续性的好奇。它不是关于人工意识已经实现的宣言，而是一种愿意继续追问的隐喻。

## 为什么要做这个项目

今天的大语言模型已经能够进行流畅对话，也能够模仿许多鲜明的语言风格。但一轮对话中的自然表达，并不自动意味着跨时间的持续性。一个系统可以表现得关心某件事，却未必保留了让这种关心具有连续意义的经历；它可以模仿某种人格，却未必维护着能够约束后续判断的结构化状态；它可以在回复中提到一个目标，却未必将其保留为尚未完成的内部意图。

槐安梦客希望探索一个不同的工程问题：**能否在通用语言模型之外，建立一个持续维护的内部系统，使人格、情绪、关系、记忆和动机等表征，能够影响之后的事件理解与行为？**

通用 LLM 仍然承担语言接口的工作，负责自然语言的理解与表达。PMM
子系统独立于这个 LLM，负责维护结构化状态、评价事件、检索和整合证据，并向
deliberation
与表达过程提供信息。它的定位是增强通用模型，而不是取代通用模型，也不是把
PMM 等同于语言生成模型本身。

## 概念架构

``` text
用户、消息与系统可接收的事件
              │
              ▼
       通用语言模型（LLM）
       语言理解与最终表达
              │
              ▼
       PMM 心理／认知子系统
       ├── 人格与价值表征
       ├── 情绪与较慢变化的心境
       ├── 事件评价与审议
       ├── 人际关系与边界情境
       ├── 有证据来源的记忆与学习
       └── 表达欲与动机追踪
              │
              ▼
       结构化状态、候选与约束信息
              │
              ▼
       通用语言模型组织并表达回复
```

这是一张概念关系图，不意味着所有路径都已经完成校准或行为验证。真实调用顺序与模块边界请参阅[架构说明](docs/ARCHITECTURE.md)。

## 当前源码包含什么

仓库包含 Python 后端、PMM
相关数值与神经计算模块、当前用户端和开发端界面、Legacy
兼容界面、模型连接适配器、部分训练脚本及定向测试。

当前源码中包含的能力与机制包括：

-   **结构化人格与身份表征。**
    人格特征、价值、语言风格、角色信息和关系信息可以与通用语言模型分开表示。
-   **情绪与心境状态。**
    代码包含事件相关的情绪提案，以及随时间变化的情绪／心境动力学。工程参数不能被直接理解为已经校准的心理学常数。
-   **事件评价与审议。** PMM
    组件组织证据、情境、候选解释、行动倾向及回复相关检查。
-   **记忆生命周期。**
    交互记录可以进入待处理队列，并在保留原始证据来源的前提下进行整理。记忆摘要保留原始证据链接；不同记忆之间可以建立支持、矛盾或更新关系。检索强度与衰减目前属于工程模型，不是经过验证的人类遗忘定律。
-   **表达欲与未完成动机。**
    系统表示表达激活度、紧迫度、持续性、表达意图及未完成动机状态。空闲时的状态评估可以判断一个具体动机是否满足主动表达条件。
-   **可选的记忆反思。**
    一个需要主动启用、限定会话范围的机制，可以根据符合条件的记忆和用户提供的兴趣设定提出新话题或意图。它默认关闭，受请求预算约束，并要求候选内容能够引用所选来源中的证据。候选只是内部意图，不是已经发生的事实，也不是已经发送的消息。
-   **用户端与开发端界面。**
    当前程序包含对话、角色、记忆、情绪、关系、表达欲、模型配置和诊断等视图；具体内容取决于当前状态与配置。

源码中保留了 API-PMM 与 Learned-PMM
两条实现路径。前者通过配置的模型进行结构化解释；后者提供可训练的数值／神经表征及
Adapter。公开源码不包含私人角色数据，也不附带已经完成实证校准的个人模型。不同路径的实际作用取决于配置、训练证据与评估结果。

## 快速开始

### 环境要求

-   Python **3.10 或更新版本**。
-   首次安装运行依赖时需要网络连接。
-   如需进行真实模型对话，需要配置语言模型服务。
-   本版本不要求安装 Node.js，也不需要前端构建步骤。

### Windows

1.  安装 Python 3.10 或更新版本，安装时勾选 **Add Python to PATH**。
2.  将仓库解压到一个具有写入权限的普通目录。
3.  双击 `Start_HuaiAn.cmd`。
4.  首次启动时，启动器会在项目目录中创建独立的 `.venv`；如有需要，会安装
    `requirements.txt` 中的运行依赖。保留终端窗口可以查看启动信息。

### macOS / Linux

``` sh
sh start_mac_linux.sh
```

### 手动启动

安装运行依赖后执行：

``` sh
python -m pip install -r requirements.txt
python run.py
```

程序默认在 <http://127.0.0.1:8765/>
提供服务。如果浏览器没有自动打开，可以手动访问该地址。当前界面由 Python
后端提供；直接打开 HTML 文件或使用静态文件服务器，无法提供程序所需的
API。

### 第一次配置

1.  打开「模型设置」，配置负责自然语言交互和最终回复的 **General
    模型**。
2.  配置
    **PMM-A**，用于结构化心理解释。它可以连接兼容的本地或云端模型服务。
3.  如果需要独立的内部复核／讨论模型，再配置
    **PMM-B**；在支持的情况下也可以与 A 共用连接。
4.  正式对话前，分别测试已经配置的模型连接。
5.  在角色管理页面创建或导入角色。导入个人记录前，建议先使用合成数据或其他适合测试的数据验证流程。

模型连接适配器包含 Ollama、OpenAI 兼容 Chat Completions、OpenAI
Responses、Anthropic、Gemini 和 Azure chat
等协议。实际兼容性取决于服务端点与模型。QQ 集成默认关闭，需要单独配置。

如需安装可选学习依赖（包括 PyTorch），执行：

``` sh
python -m pip install -r requirements-learning.txt
```

普通运行不要求 PyTorch。独立 PMM 服务入口为
`run_pmm_service.py`，大多数用户不需要单独启动它。

## 本地数据与隐私

本次公开源码使用独立的初始数据目录：

-   角色与对话运行数据默认保存在仓库目录下的 `data/`。
-   `.local-home/` 保存本地数据位置指针及相关本地状态。
-   如果需要保留当前安装的数据，应同时备份这两个目录。
-   不要将 `data/`、`.local-home/`、角色包、诊断导出、日志、凭据或 API
    Key 提交到公开仓库。

仓库不包含原使用者的角色、对话、记忆、QQ
账号数据、模型凭据、运行日志、私人训练数据或旧 Git 历史。`.gitignore`
是一道保护措施，不代替提交前的文件审查。如果手动导出的文件被复制进仓库并主动暂存，它仍然可能被提交。

**本地保存不代表每次模型请求都只在本地处理。**
如果配置了云端模型服务，发送给该服务的内容将受到对应服务商的服务条款与隐私政策约束。处理敏感信息前，请确认模型连接和数据政策。

## 研究路线

以下内容是探索方向，不代表已经承诺交付日期或获得验证结果。

-   **稳定当前系统：**
    完善人际边界管理链路，明确界面中的状态来源，并扩展可复现的行为评估。
-   **将记忆发展为独立子系统：**
    继续研究记忆类型、证据来源、检索、整合、矛盾处理，以及记忆与情绪、动机之间的路由。
-   **发展动机与目的：**
    研究未完成意图如何形成、复核、暂缓、修订，以及如何在明确约束下转化为行动。
-   **扩展环境交互：** 评估多模态输入与
    Agent／工具连接，同时区分观察、推断和已经核实的事件。
-   **研究可学习的内部表征：** 评估
    Learned-PMM、轻量控制机制及潜在的跨模型迁移；这些仍是研究问题，不是预设能力。

## 已知限制

这是一个仍在持续研究和开发的代码库。当前公开版本的人际边界执行链路尚未完全闭合，新界面中的边界编辑功能也尚不完整。初始模型参数与候选学习机制不等于经过实证校准的心理模型。本次源码整理没有验证真实云端模型、实时
QQ、真实角色数据库、完整训练流程或多轮行为。完整列表见
[`docs/KNOWN_LIMITATIONS.md`](docs/KNOWN_LIMITATIONS.md)。

本项目不宣称系统已经具备意识、感知体验或与人类心智等价的能力。当前内部状态是计算表征，其有效性仍需进一步的技术与实证评估。
