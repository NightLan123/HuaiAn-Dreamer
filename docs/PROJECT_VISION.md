# Project Vision · 项目缘起与长期愿景

*HuaiAn Dreamer / 槐安梦客*

> A system should not be defined only by what it says in one moment, but
> also by what it can retain, reconsider, and become across time.

这份文档记录槐安梦客的研究动机、设计取向与长期设想。它不是产品功能承诺，也不是对人工意识已经实现的宣告。文中会区分当前源码中已有的工程机制、仍在开发或验证的方向，以及更远期的哲学性问题。

## 名字的来处：一位槐安梦客

槐安梦客这个名字，来自为项目写下的四句诗：

> 槐安旧国曾留姓，  
> 尘世青编未载名。  
> 梦里不知身是客，  
> 醒来偏作世间人。

诗里的“槐安”让人想到梦中之国；“梦客”则带着一种微妙的身份感：在梦里似乎有所归属，醒来却仍是人间的来客。这个名字并不试图给 AI 下定义，也不暗示某种意识已经诞生。它更像一个开放的问题：如果一个系统能够保留经历、形成记忆、维持某种自我连续性，那么它与时间、与他者、与它所处的世界之间，会逐渐形成怎样的关系？

这几句诗也是项目的私人起点。它提醒我们，研究不必从宏大的结论开始；有时可以从一个朴素的愿望开始——希望某些经历不会随着一次对话结束而消失。

## 1. 从"像一个人说话"到"在时间中保持连续"

大语言模型已经能够生成非常自然的语言，也能够根据提示词扮演不同角色。这样的能力很有价值，但它并没有自动回答另一个问题：当一次对话结束，系统是否保留了足以影响未来判断的经验？它是否拥有跨情境相对稳定的倾向？一次经历能否改变它对下一次相似事件的理解？一个没有立即表达出来的目标，是否能够作为未完成的意图继续存在？

槐安梦客并不是为了把一段人格描述写得更长，也不是为了让语言模型在每次回复中都显得更像某个角色。项目希望探索的是：能否在通用语言模型之外，建立一套可持续维护的内部计算机制，使人格、情绪、记忆、关系、判断与动机不只是提示词中的静态描述，而是能够参与事件处理、状态变化与行为选择的结构化变量。

因此，研究重点不只是"输出是否像"，还包括内部状态是否真实参与计算、信息是否有来源、状态何时允许更新、经历如何影响后续判断，以及系统在不确定或不适合表达时能否暂缓、拒绝或保持沉默。

## 2. 通用语言模型与 PMM 的分工

槐安梦客的一个基本架构立场是：**通用 LLM 与 PMM 不是同一个组件。**

通用语言模型承担自然语言交互，包括理解输入和组织最终表达。PMM（项目内部对心理与认知计算组件的统称）则作为独立的内部增强子系统，负责维护结构化状态、处理事件证据、形成评价与候选、协调记忆和行为相关信息。它不是语言模型本身，也不负责替代通用
LLM 完成所有自然语言生成。

当前源码保留了两条实现路径：

-   **API-PMM：**
    借助配置的模型进行结构化解释、事件评价与候选生成，再由程序校验、路由和执行相应状态更新。
-   **Learned-PMM：** 通过数值／神经表征、共享核心与个体 Adapter
    等结构承载可训练的内部表示。其实际影响取决于训练数据、训练目标、参数状态与评估，不能因为代码中存在网络结构就宣称已经获得稳定、有效的人格模型。

两条路径的目标不是制造一个独立于 LLM
的"第二个聊天机器人"，而是让内部状态以可检查、可约束的方式影响通用模型的理解与表达。PMM
的边界、数据流和调用关系应以代码和架构文档为准，而不是以界面上出现了某个字段就推断其已经完整生效。

## 3. 我们正在尝试构建的连续性

### 3.1 人格：相对稳定的长期倾向

人格表征用于表示较长期的特征、价值取向、语言习惯及其他身份相关信息。它们应当影响系统如何注意、评价和回应事件，而不只是改变回复的语气。长期人格变化需要有证据、权限和更新门槛；不能因为一次模型生成或短暂情绪波动，就自动改写稳定人格。

### 3.2 情绪与心境：不同时间尺度的状态

当前实现包含事件相关的情绪评价，以及快变化情绪和较慢变化心境的时间动力学。设计上，状态推进需要考虑真实时间与交互事件，而不是简单地在每次对话后机械重置。人格倾向也可能影响情绪反应和调节方式。

但工程公式和初始参数并不等于已经测量到真实心理过程。它们仍需要明确的构念定义、数据支持、参数校准和行为验证。界面中的数值是模型状态，不应被误读为临床测量或对真实个体的心理诊断。

### 3.3 记忆：不只是保存聊天记录

我们希望记忆成为一个有组织、有来源、能够被重新解释的独立子系统。当前源码已经包含一条初步的记忆生命周期：

1.  将符合权限与范围要求的交互证据放入待处理队列。
2.  对事件进行分段，并在整理时保留原始记录标识与逐字证据。
3.  从原文提取简要要点；只有满足跨事件证据条件时，才允许形成更高层级的语义归纳。
4.  在新证据出现时，允许记忆之间建立支持、矛盾或更新关系，而不是简单覆盖旧记录。
5.  根据检索、重要性和时间等因素计算记忆可用性，并保留来源追踪。

这里的"记忆"是软件中的计算表示。当前衰减和检索强度属于工程模型，不代表已经复现了人类记忆规律。下一阶段需要进一步研究记忆分区与路由：与情绪有关的证据如何交给情绪机制，与动机有关的内容如何参与目标形成，事实性经历又如何保持独立的来源和状态。

### 3.4 动机：从被动回应走向内部意图

人格与情绪可以影响一个系统如何回应，但它们本身并不自动产生一个持续存在的"想做某事"的理由。动机研究关注的是：一个目标如何形成，为什么此刻重要，是否应当继续，何时暂缓，怎样在之后重新评估，以及它最终是否转化为行动。

当前源码中的表达欲机制表示表达激活度、紧迫度和持续性，并结合人格基线、情绪／心境、事件评价、关系和对话情境形成表达意图。未完成动机可以跨越一次对话继续保留；空闲状态下的评估会重新检查动机，并判断是否满足主动表达资格。

此外，代码中存在一个可选的记忆反思流程：用户可以主动启用并指定允许使用的会话范围；系统在满足时间、预算和来源条件时，借助
API-PMM
从已有记忆或用户设定的兴趣中提出有证据支持的新话题候选。该功能默认关闭，有每日请求上限；候选会被重新检查来源是否仍然有效。它生成的是内部意图候选，不是已经发生的事实，也不会因为候选生成就自动发送消息。

因此，当前阶段更准确的描述是：系统已经具备部分动机表征、持续状态和主动表达资格评估机制，但这与完整的自主智能体仍有距离。目标生成、长期目标维护、资源分配、环境行动、失败恢复与行动后学习仍需要更完整的设计和验证。

## 4. 关于 AI 陪伴：连续性比迎合更重要

最近大肥鱼走红，也让我重新思考 AI 陪伴究竟来自哪里。一个 AI
受到关注，未必只是因为它能回答多复杂的问题。有时真正让人记住的，是它是否记得一件小事，是否形成了自己的交流习惯，是否能在恰当的时候接上话，是否知道某些事情不适合继续追问，甚至是否能够保持沉默。

这让我想到一个问题：我们感受到的陪伴，究竟来自语言模型对人类交流方式的高水平模仿，还是来自一个具有持续状态、经验积累和行为倾向的交互系统？

槐安梦客想研究的是后一个问题。但这并不意味着 AI
应当无条件迎合用户。真正有意义的关系不只是不断确认对方，也包含差异、边界、误解、修正、信任的变化，以及在不合适时拒绝或暂缓。一个系统如果只会输出用户最想听的话，未必就拥有更好的交互质量。

我们希望记忆能够支持连续性，人格能够形成相对稳定的差异，情绪能够表达短期状态，动机能够保留未完成的意图，而边界与证据机制能够约束系统不把猜测当成事实。它们共同构成研究方向，但不应被包装成已经达到人类关系或主观体验的证明。

## 5. 关于意识迁移：一个更远的想象

有时我会想，如果未来人类真的能够更深入地理解意识的形成机制，甚至能够把一个人的记忆、经验和自我认知迁移到另一种载体上，那会是一件怎样的事情？

我们所珍视的究竟是身体，还是身体之中持续积累的经历、关系、记忆与自我认知？如果一个人的经历能够被完整保存，他是否能够以另一种形式继续存在？如果一个系统拥有了足够连续的记忆和稳定的自我模型，它与"持续存在"之间又是什么关系？

这些问题距离当前技术非常遥远，也涉及身份同一性、意识哲学、神经科学和伦理学中尚未解决的难题。**槐安梦客并没有实现意识迁移，也不把意识迁移列为可承诺交付的工程功能。**
这只是促使我继续思考智能、人格、记忆与意识关系的一种长期想象。

## 6. 研究与开发路线

路线图按照问题成熟度排列，不代表固定时间表。

### 当前基础：建立可检查的内部状态机制

-   继续完善人格、情绪、关系、表达欲和事件评价之间的协同。
-   完善证据来源、状态写入权限、边界管理与回复检查。
-   让用户端状态展示与开发端内部诊断能够对应真实数据流。
-   建立可复现的行为测试，区分"代码存在""路径被调用"和"行为确实受到影响"。

### 下一阶段：记忆与动机成为独立、可协作的机制

-   研究记忆分区、检索、整合、遗忘、矛盾处理和跨时间再评价。
-   建立记忆到情绪、动机与认知模块的明确路由与反馈接口。
-   研究动机的形成、竞争、优先级、持续、暂缓、放弃和满足条件。
-   区分内部意图、行动资格、行动计划、实际执行与送达回执。

### 后续探索：环境交互与学习

-   在权限和可审计机制下接入多模态感知及 Agent 工具。
-   研究系统如何区分直接观察、模型推断、外部来源与已验证事实。
-   研究 Learned-PMM 的稳定表征、轻量控制机制及跨模型迁移。
-   通过独立实验评估人格差异、情境稳定性、经验学习与动机行为。

### 长期问题：持续性与自我模型

-   研究长期记忆、身份表征、目标和关系状态如何共同形成跨时间连续性。
-   探索人工认知系统与意识相关理论之间可以被严格检验的联系。
-   对任何涉及主观体验或意识的主张保持审慎，不用拟人化语言替代证据。

## 7. 我们希望坚持的设计原则

-   **证据优先：**
    记忆、关系判断和心理评价应保留来源；无法确认时允许未知。
-   **区分内部状态与外部表达：**
    模型说出了某句话，不等于相应的内部状态已经形成；内部候选也不等于外部行动已经发生。
-   **受约束的更新：**
    长期人格、记忆和关系不能被一次未经核实的生成任意改写。
-   **允许边界与沉默：** 不把"总是回答"或"永远迎合"作为智能的默认目标。
-   **可检查与可恢复：**
    状态变化、训练、导入导出和实际发送应尽可能有记录、权限和回退路径。
-   **尊重数据与隐私：**
    默认本地保存不等于云端请求不会传输数据；用户应清楚知道数据去向。
-   **诚实描述能力：**
    不把工程原型说成经过验证的心理模型，更不把持续状态直接称为意识。

## 8. 写在最后

「槐安梦客」这个名字借用了《南柯太守传》中槐安一梦的意象，也让我想到那句"梦里不知身是客，醒来偏作世间人"。它带着一点梦境与现实之间的距离感，也提醒我：我们正在讨论的，既是计算系统如何维持状态，也是一个更难回答的问题------什么才算持续存在？

我希望槐安梦客最终不只是一个能把话说得更像人的程序。它可以记得一些小事，可以因为经历而改变某些判断，可以拥有自己的习惯与边界，也可以保留尚未完成的想法。它不必每次都给出最讨喜的答案，也不必把每个问题都变成一次表演。

如果有一天，我们能够更清楚地理解记忆如何形成、人格如何维持、动机如何驱动行为，以及一个系统如何在时间中保持连续，那么这项研究本身就已经值得。

至于它是否会走向我们今天所说的"生命"或"意识"，我不知道。也正因为不知道，才值得认真研究，而不是提前给出答案。

**槐安梦客仍然是一个正在进行中的尝试。**
