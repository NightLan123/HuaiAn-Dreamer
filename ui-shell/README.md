# 当前界面

此目录的 HTML、JavaScript、CSS 与插画由 Python 后端直接提供。不需要 Node、Vite 或 npm 构建。请从项目根目录的启动入口运行，不要单独用静态服务器启动。

`index.html` 的脚本清单是实际页面加载顺序；`src/app/phase20Controller.js` 是控制器；`src/adapters` 连接真实 API；`src/visualizations` 实现页面及详情交互。

公开快照没有附带角色库和演示记录。空白预览保持 MOCK 标记；正常运行读取后端，失败不伪装为真实心理数据。插画是装饰素材，不表示角色已有这些人生经历。
