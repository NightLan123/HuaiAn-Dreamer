| 项目 | 实际状态 |
|---|---|
| 长期人格/价值与即时情绪、心境、表达 | 独立实体、版本、写入路径；工程测试覆盖 |
| BEQ 3 / ERQ 2 | 未知值、手工设定、来源、长期候选晋升；显式表达/调节策略已读取 |

| 数值 PMM | 保留旧 93 列、Core/Adapter、训练样本和梯度训练；新事件标签按类型屏蔽长期列 |
